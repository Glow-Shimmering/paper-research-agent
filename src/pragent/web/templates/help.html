使用帮助

PRAgent 的三条核心工作流与安全边界说明。

推荐工作流

  1. 单篇精读：创建项目 → 从来源库选择论文 → 提出研究问题 → 在 Deep Reads 生成九栏精读卡 → 展开证据核对原文 → 编辑并导出。
  2. 多篇比较与综述：选择 2–20 篇已精读来源 → 生成比较矩阵 → 基于比较生成综述提纲 → 逐节生成带证据的章节草稿 → 切换引用样式导出 DOCX/Markdown。
  3. 发现与入库：在 发现 并行搜索 arXiv / Semantic Scholar / Crossref（同一论文自动去重）→ 下载 PDF 或抓取网页快照 → 正文进入同一检索链路 → 加入项目。

任务与恢复

  • 所有生成任务都在 任务中心 排队执行；页面刷新或服务重启后任务与产物都会恢复。
  • 执行中的任务可以请求取消，但只能保证在阶段边界停止，不会中断正在进行的模型请求。
  • 来源更新后旧的精读卡/比较/综述会标记为 stale，历史版本始终可读，重新生成会追加新版本。

隐私与安全边界

  • 使用云端 DeepSeek 时，模型会收到你的问题与命中的论文片段；本地索引不代表内容永不离开本机。
  • 写入与联网操作必须经过确认；确认以冻结参数执行，刷新页面或重启服务后仍可安全确认或取消。
  • 网页快照只作为文本保存和阅读；界面不会渲染原始 HTML，也不会泄露服务器绝对路径。
  • 引用与新鲜度校验只证明来源身份和当前性，不能自动证明论断在语义上被证据支持；请人工核对。
