# PRAgent Web V1.2 可点击产品原型

这个目录只用于确认产品逻辑和交互方向。它不连接现有后端，不读取 `.env`，不会联网、下载论文、调用模型或写入 SQLite。

## 打开方式

最简单的方式是直接双击 `index.html`。

也可以在仓库根目录运行：

```powershell
python -m http.server 4173 --directory prototypes/agent-research-v1
```

然后打开 <http://127.0.0.1:4173/>。

## 评审路径

1. 点击左侧“新项目”，填写项目名称并选择项目工作区。
2. 完成主流程后，在精读或对比阶段使用左侧快捷追问，验证跨阶段问答和修改。
3. 在对比阶段输入“新增推理成本维度”，检查矩阵是否立即增加一列。
4. 在综述页点击“完成”，检查 MD 自动保存与项目公共记忆状态。
5. 点击“新建对话”直接进入无标题对话；首次提问后检查自动标题，并使用“改”手动重命名。

项目、多个对话、页面进度、公共记忆和反馈只保存在当前浏览器的 `localStorage`。“完成”只模拟把 MD 写入你填写的项目工作区，不会弹出下载，也不会实际写入该目录。顶部“重置原型”会清除这些原型数据，不影响正式 PRAgent 数据。
