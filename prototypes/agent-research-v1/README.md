# PRAgent Web V1 可点击产品原型

这个目录只用于确认产品逻辑和交互方向。它不连接现有后端，不读取 `.env`，不会联网、下载论文、调用模型或写入 SQLite。

## 打开方式

最简单的方式是直接双击 `index.html`。

也可以在仓库根目录运行：

```powershell
python -m http.server 4173 --directory prototypes/agent-research-v1
```

然后打开 <http://127.0.0.1:4173/>。

## 评审路径

1. 在首页选择“主题调研到综述”，然后点击左侧“开始规划”。
2. 修改并确认研究计划，再批准原型操作。
3. 调整候选论文，进入执行页并点击“快速完成演示”。
4. 依次检查精读、证据、对比矩阵和综述草稿。
5. 每页右上角点击“反馈”，保存问题；最后点击“复制全部反馈”。

页面进度和反馈只保存在当前浏览器的 `localStorage`。顶部“重置原型”会清除这些原型数据，不影响正式 PRAgent 数据。
